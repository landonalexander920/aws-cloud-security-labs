# AWS Cloud Security Labs

I'm Landon Alexander, a Cybersecurity and Information Assurance student at Frostburg State University. This is where I document my hands-on AWS labs.

In every lab I explain what I built and why I made each security decision, written so it makes sense whether you work in security or not.

Everything here runs in my personal AWS account. Account IDs, IP addresses, and instance details are blurred in every screenshot.
